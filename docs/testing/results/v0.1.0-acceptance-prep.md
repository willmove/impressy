## Actions 现状（阻塞 macOS/Linux 证据）

`origin/main@f14d030` 的 CI run
<https://github.com/willmove/impressy/actions/runs/30205569689>
在约 2 秒内全部 job `failure`，且 `runner_name` 为空——**runner 未真正拉起**，不是测试断言失败。
在 Actions 能正常调度之前，无法写入合法的 `ci_run_url` 证据。

排查建议：仓库 Actions 权限、账单/分钟额度、组织策略；修复后对精确候选
`gh workflow run` 或 push 空提交重跑，确认 `CI` 全绿再汇总 JSON。
