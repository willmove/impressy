## 阻塞打 tag 的条件

任一成立则 **不要** 执行 `git tag v0.1.0`：

1. 正式验收 JSON 未提交或验证器失败  
2. macOS / Linux / Windows 10 证据仍缺或 SHA 不一致  
3. Windows / macOS 签名 secrets 未配置且仍要发「正式」产物  
4. `main` 工作树不干净或与 `origin/main` 分叉未解决
