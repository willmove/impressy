# v2 AI 图片功能真机验收清单

本清单验证自动测试无法证明的真实 Provider 契约、账户错误、生成质量与**保持不变项**。
验收必须使用 release 构建和验收人自备的 Seedream、Nano Banana、OpenAI API Key；密钥
不得写入仓库、截图、日志或结果文件。先完成 [`v1-desktop-acceptance.md`](./v1-desktop-acceptance.md)
的本地功能回归，确认 v2 没有破坏离线承诺。

## 环境与安全

- [ ] 记录精确 Git SHA、Rastery 版本、系统、GPU、显示缩放、日期和验收人。
- [ ] 三家 API Key 均可在设置中保存、替换和删除；应用 TOML 与日志中不存在密钥片段。
- [ ] Windows Credential Manager / macOS Keychain / Linux Secret Service 中的条目可被系统工具确认。
- [ ] 断网时所有 v1 本地功能仍可用；AI 请求显示双语网络错误且应用保持可复用。
- [ ] 用测试账户触发无效密钥、余额不足、限流和内容政策阻止，分别得到正确语义错误；内容阻止返回零张图。

## Provider 契约

对 Seedream、Nano Banana、OpenAI 各执行一次文生图和参考图生成：

- [ ] 请求成功，返回图片可预览并能多选保存；保存名含时间戳和顺序号。
- [ ] 切换 Provider 后比例、单次最大结果数和最多参考图提示同步变化。
- [ ] OpenAI 局部消除可拖拽 / 缩放选区并只修改透明掩码区域；不支持掩码的 Provider 会禁用生成并解释原因。
- [ ] 生成进度指示、等待文案、完成数量和错误文案可在中英文之间即时切换。
- [ ] 生成历史只保存在本地，可一键清除，不包含提示词或 API Key。

## AI 改图与行业工具

每项至少准备一张清晰、许可用于测试的输入图；保存原图与所有输出摘要。逐项确认锁定提示词不出现在 UI：

- [ ] 12 个 AI 改图场景全部可发起；白底图为纯白背景，自由改图接受用户提示词。
- [ ] 老照片修复的修复 / 上色 / 清晰度三档可多选；按住结果可显示原图，人物身份不变。
- [ ] 证件照的一寸输出为 295×413、二寸为 413×579、签证照为 600×600；蓝 / 红 / 白底和正装符合选择，五官不变。
- [ ] 头像工坊 9 种风格可选且最多同时 6 种；选择 N 种最多返回 N 张 1:1 图片。
- [ ] 表情包 12 种情绪可批量选择，输出人物身份一致且表情符合档位。
- [ ] AI 写真 8 个主题均可用，五官与身份不变，场景和服装符合主题。
- [ ] 模特试穿包含亚洲女模特 / 咖啡馆档位；服装款式、颜色、材质和细节不变。
- [ ] 商品改色支持酒红、藏青、雾霾蓝、多选和自定义色；商品外形与材质不变。
- [ ] 促销海报四类活动均可用，标题可填或留空；输出精确为 1200×1600（3:4）。
- [ ] 平台适配输出精确为 800×800、1242×1656、900×383、1080×1920；近似比例走本地裁切不产生 AI 账单，差异较大时先扩图；主体不被裁掉且无拉伸。
- [ ] 封面图四个平台均可生成粗体排版；标题内容正确。
- [ ] 文章配图可重复生成同系列商务渐变 / 编辑风格，图片中没有文字。
- [ ] 菜品图光影、色泽和背景得到改善，菜品本身、分量、摆盘不变。
- [ ] 室内预览最多同时选择 4 种风格；房间结构、门窗和固定设施不变。

## 海报设计

- [ ] 四种 AI 背景风格与 9:16 画布可用，科技发布风符合档位。
- [ ] 主标题、副标题、角标均由 GPUI 平台文字系统显示；Windows 使用 DirectWrite，中文无错字或缺字。
- [ ] 三个文字图层均可拖动位置并拖动蓝色把手缩放。
- [ ] 导出的 1080×1920 PNG 由本地离屏合成，逐层位置、字号、文字和预览一致，文字清晰。

## 结论

任一 Provider 契约失败、任一**保持不变项**失败、密钥泄漏、尺寸错误或 v1 离线回归失败，
均不得把 v2 标记为可发布。真实服务商可能随时变更接口或模型；发现漂移时先更新 ADR-0004
和假传输契约测试，再重新执行本清单。
