# v1 桌面真机验收清单

本清单覆盖无法在 headless 开发机验证的 GPUI 渲染、交互手感、系统集成与性能指标。
每个平台均使用 `cargo build --release -p rastery-app` 的 release 构建验收；不要用 debug
构建记录性能数据。

正式记录复制 [`results/v1-desktop-acceptance.example.json`](./results/v1-desktop-acceptance.example.json)
为 `results/v1-desktop-acceptance.json`，填写完整 Git SHA、四种桌面环境、三次以上性能样本、
测试资源 SHA-256 与安装包结论。提交前运行：

```shell
python scripts/verify_desktop_acceptance.py
```

发布工作流把该验证器作为第一道门禁；缺记录、记录过期、指标不合格或安装包未验收都会阻止发布。

可复测资源用确定性生成器创建，不把 50MP 图片和 100 张批处理样本提交进 Git：

```shell
cargo run --release -p rastery-core --example acceptance_assets -- target/acceptance-assets
```

生成器会按规范化相对路径和文件内容输出跨平台一致的目录 SHA-256，把它写入结果 JSON 的
`resources.generated_sha256`。二维码、50MP 预览、美化和 100 张批处理都使用这批资源；
EXIF 项另使用一张含真实相机、镜头、时间与 GPS 字段的照片，并把文件摘要写入
`resources.exif_photo_sha256`。

## 共通功能

- [ ] 首次启动显示四大板块；两个 AI 板块和三个视频功能只显示 v2「开发中」。
- [ ] 中文 / English 可运行时切换，应用和 gpui-component 文案同步切换，重启后保留语言。
- [ ] 默认导出格式、质量和最近输出目录重启后保留；损坏配置会恢复默认值并显示提示。
- [ ] 文件选择、文件拖放、跨应用粘贴图片均可用；复制结果后可粘贴到另一应用。
- [ ] 图片编解码与处理期间窗口仍可移动、切换板块和响应点击。
- [ ] 完成导出后「打开输出目录」能启动平台文件管理器。
- [ ] 无效格式、损坏图片、权限不足和磁盘空间不足分别显示正确的双语错误类别。

## 八个 v1 功能页

- [ ] 图片编辑：五种裁剪比例均正确显示；选框可移动、八把手可缩放；角把手保持比例；
      旋转、缩放、PNG/JPEG/WebP 导出结果正确。
- [ ] 拼图拼接：纵向、横向、网格布局正确；列数、间距和四种背景可调；三种格式可导出。
- [ ] 批量处理：格式转换、压缩、缩放、文字水印、图片水印均可用；右下角和平铺位置正确；
      失败项名称单独显示且不会中断其余项目；输出名包含原文件名和顺序号。
- [ ] 切图：3×3 和自定义行列均产出准确数量；文件名含顺序号与 `rNcN` 网格位置。
- [ ] 二维码：文本和 URL 可生成；尺寸、纠错级别、任意前景色与背景色有效；系统扫码器可识别；
      导入截图质量的二维码能显示解码内容。
- [ ] EXIF：相机、镜头、焦距、光圈、快门、ISO、时间和 GPS 按存在情况显示；清除后用
      第三方 EXIF 工具确认无 GPS 与设备字段，同时像素不变。
- [ ] 截图美化：调圆角、边距、背景、描边、阴影时预览持续更新；透明背景导出 PNG 后
      圆角外 alpha 为 0。
- [ ] GIF：100–800ms 延迟、自定义尺寸、正序、倒序、乒乓均正确；系统看图工具和常用
      消息应用可正常播放。

是否要把单张图内部处理拆成更细的进度阶段。
